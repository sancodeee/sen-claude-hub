# 权威信息源清单

本文件为 TripForge **调研阶段**提供按信息类型分类的权威站点，目的是：让联网核实时**优先找对源、用对方式、少走弯路、不误用 UGC 内容**。
内容写什么见 `template.md`，HTML 设计见 `assets/report-template.html`，本文件只管「去哪查、怎么查」。

> 站点可用性最后核验：2026-06-15（已实测抓取/搜索，标注见下）。网址与反爬策略会变；调研时以实际可达为准，打不开就回退到对应类目的官方运营方或搜索引擎。

## 一、可信分级（结论可信度）

| 标签 | 含义 | 使用规则 |
| --- | --- | --- |
| 🏛️ **官方权威** | 运营方 / 政府 / 景区 / 航司 / 气象台官方 | 结论可直接采信，仍注明来源与核验日期 |
| 🛒 **主流平台** | 预订 / 聚合 / 点评平台 | 价格、营业时间、班次须与 🏛️ 官方或第二来源**交叉验证**后才采用 |
| 💬 **UGC 社区** | 用户生成内容（攻略 / 笔记 / 问答 / 短视频） | **默认含大量营销软广、探店推广、刷量好评**，不代表真实情况。**仅用于发现线索**，须逐条交叉验证；**不得直接作为结论写入正文** |

## 二、访问方式（怎么才拿得到信息，决定省不省 token）

| 标签 | 含义 | 操作 |
| --- | --- | --- |
| 🌐 **可直抓** | WebFetch 能直接读到所需内容（已实测或为静态页） | 直接抓取目标页提取信息 |
| 🔍 **走搜索** | 站点反爬 / 动态渲染 / 需交互，直接抓官方 URL 拿不到 | **不要直接抓官方 URL**；用 WebSearch + 具体查询词命中聚合页/快照，关键数字再回官方核对 |
| 📱 **App / 登录墙** | 网页基本取不到（登录墙 / App-only / 强反爬） | 只能靠搜索引擎收录的零散快照；UGC 按营销甄别规则处理，**勿直引** |

> **⚠️ 省 token 铁律：** 凡标 🔍 / 📱 的站点**一律不要直接 WebFetch 其官方 URL**——多会返回验证页、空白或登录墙，纯属浪费。改用 WebSearch + 精确查询词，例如：
> - `北京南 烟台 高铁 时刻 票价`、`烟台 鲅鱼水饺 人均 大众点评`、`烟台 万达 到 养马岛 打车 时间`
>
> **通用原则：** 同一条易变信息，🏛️ 官方 > 🛒 平台 > 💬 UGC；至少交叉核验两处；无法核实标 `❓`，不得编造。

## 1 · 天气与气象（☀️ 强依赖点位排程的依据）

**国内**

- 🌐🏛️ 中国天气网 `www.weather.com.cn` —— 逐日 / 逐小时预报、生活指数（**实测可直抓 7 天预报**）
- 🌐🏛️ 中央气象台 `www.nmc.cn` —— 权威预报、预警、台风路径
- 🌐🛒 和风天气 `www.qweather.com` —— 逐小时、空气质量、紫外线

**海外**

- 🌐🛒 AccuWeather `accuweather.com` —— 全球逐小时与体感
- 🔍🛒 Windy `windy.com` —— 风力 / 浪高 / 云图（动态地图，**走搜索取结论**；海边、登高、航海有用）
- 🌐🏛️ 目的地国家气象局官网（美国 `weather.gov`、日本 `www.jma.go.jp`）—— 当地最权威

> 用途：判断「好天放刀刃上 / 坏天换室内」的对调排程，必须标 ⚠️ 出行前再确认。

## 2 · 火车 / 高铁

**国内**

- 🔍🏛️ 12306 `www.12306.cn` —— 唯一官方购票（**站本身需交互/反爬**）：**车次 / 时刻 / 票价用 WebSearch 查聚合结果**，购票与最终余票以官网/App 为准

**海外**

- 🔍🛒 Trainline `thetrainline.com` —— 欧洲多国车次比价（走搜索）
- 🌐🏛️ 各国铁路官网（日本 JR、德国 DB `bahn.de`、法国 SNCF）—— 时刻与票价最权威，信息页多可直抓

------

## 3 · 机票 / 航班动态

**国内**

- 🌐🏛️ 各航司官网 —— 票价与改签规则最权威，常有官网价
- 🔍🏛️ 飞常准 `variflight.com` —— 航班动态、准点率（动态页，走搜索取结论）
- 🔍🛒 携程 / 去哪儿 —— 比价聚合，**走搜索**，下单前核对航司官网

**海外**

- 🔍🛒 Google Flights `google.com/travel/flights` —— 全球比价、价格趋势（动态，走搜索）
- 🔍🛒 Skyscanner `skyscanner.com` —— 多航司聚合比价（走搜索）

------

## 4 · 地图 / 公交 / 打车（交通方式与耗时）

**国内**

- 🔍🏛️ 高德地图 `amap.com`、百度地图 `map.baidu.com` —— 路线数据走 API/App，**纯抓取拿不到**；用 WebSearch 查「A 到 B 公交/驾车 耗时」，或让用户自行用 App 实时查

**海外**

- 🔍🏛️ Google Maps `maps.google.com` —— 全球路线（动态，走搜索/让用户实时查）
- 🔍🛒 Citymapper —— 大城市公共交通换乘（伦敦 / 纽约 / 东京等）

> 用途：每段交通的「方式 + 耗时 + 费用区间」、餐厅是否顺动线；耗时给区间并标 ⚠️，实时以 App 为准。

------

## 5 · 景点门票 / 开放预约 / 文旅官方

**国内**

- 🌐🏛️ 景区官网 / 官方公众号 —— 门票价、开放时间、预约名额、季节性开放**以此为准**（信息页多可直抓，公众号内容走搜索）
- 🌐🏛️ 文化和旅游部 `www.mct.gov.cn`、各省 / 市文旅厅（局）官网 —— 政策、公告、官方推荐（**实测可直抓**）
- 🔍🛒 携程门票 / 美团 —— 价格与可订情况参考（走搜索），须与官方核对

**海外**

- 🌐🏛️ 景点 / 博物馆 / 国家公园官网 —— 门票、预约、闭馆日最权威
- 🔍🛒 GetYourGuide `getyourguide.com`、Klook `klook.com` —— 门票/一日游聚合（反爬，走搜索）

## 6 · 酒店住宿

**国内**

- 🔍🛒 携程 / 美团 —— 国内房源与点评（走搜索）
- 🌐🏛️ 地图 App / 网页 —— 核对片区位置、距车站 / 海边 / 老城的实际距离

**海外**

- 🔍🛒 Booking `booking.com`、Agoda `www.agoda.com` —— 海外主流预订（**实测直接抓为空白，走搜索**）
- 🌐🏛️ 酒店官网 —— 大型连锁常有会员价与免费取消，下单前比一比

------

## 7 · 餐饮（营业时间 / 人均 / 口碑）

**国内**

- 📱🛒 大众点评 `dianping.com` —— 店名/人均/营业时间/排队（**实测被美团反爬拦截**）：用 WebSearch 查「店名 + 城市 + 人均 + 点评」，结合评价甄别游客店 / 套路店

**海外**

- 🌐🛒 Google Maps 商户信息 —— 营业时间、评分、菜单照片，海外最实用
- 🌐🛒 TripAdvisor `tripadvisor.com` —— 评价与排行参考

> 用途：给「具体店名 + 招牌菜 + 人均区间 + 所在街区 + 是否易排队」，避免停在「找本地老店」的概括层。

## 8 · 潮汐 / 日出日落 / 赶海（呼应「看景诉求」）

- 🌐🏛️ 国家海洋预报台 `www.nmefc.cn` —— 潮汐、海浪、赶海窗口
- 🔍🛒 潮汐表类工具 / 当地潮汐预报 —— 赶海、礁石、海边日出日落的安全与最佳时段
- 🌐🛒 日出日落查询 `sunrise-sunset.org` —— 任意地点的日出 / 日落 / 蓝调时刻

> 用途：判断日出 / 日落 / 赶海是否值得安排、要不要早起绕路，落进「看天调度」。

## 9 · 综合攻略 / 避坑（💬📱 仅发现线索，须交叉验证）

- 📱💬 小红书 —— 候选点位、机位灵感（**实测登录/App 墙，抓不到**，仅搜索引擎快照）
- 🔍💬 马蜂窝 `mafengwo.cn` —— 游记、行程、问答（走搜索）
- 🔍💬 海外 Reddit 对应城市 / 旅行版块、Lonely Planet 论坛、TikTok / Instagram

> ⚠️ **强制：** UGC 只用于**发现候选与避坑线索**，凡价格 / 营业时间 / 预约 / 班次 / 开放状态，一律回到 🏛️ / 🛒 源核实后才写入报告，并标来源与核验日期。

### 营销帖甄别（国内外社交平台同理，写入前先过筛）

社交平台（小红书 / 抖音 / 马蜂窝 / TikTok / Instagram / Reddit 等）充斥**探店软广、恰饭推广、刷量好评、摆拍滤镜**，与真实体验经常脱节。命中以下信号的内容**视为营销线索而非事实**，必须降权并交叉验证：

- **通篇无缺点、全程彩虹屁**，只夸不提任何短板 / 排队 / 性价比问题；
- **统一话术 / 同款文案 / 同款机位**短期内集中出现（一批账号刷同一家店或同一景点）；
- **强引导消费**：带门店定位、团购链接、优惠码、"私我领券"、"报我名字有折扣"；
- **图文与实物不符**：重滤镜摆拍、"小众秘境"实为人挤人、"出片地"现场平平；
- **博主属性可疑**：旅游 / 探店带货号而非普通游客，主页清一色商单。

**甄别动作：**

- **看差评和翻车帖**：主动搜"X 避雷 / 踩雷 / 真实 / 不推荐 / 难吃"，与好评对冲；
- **优先本地人视角**而非旅游博主；同一结论要求**多个互不关联的来源**印证；
- **任何可核实项回到 🏛️ 官方 / 🛒 平台**确认（价格、营业时间、是否需预约、是否已关停）；
- 经甄别仍存疑的，按 `❓` 处理或直接不写，**宁缺毋滥**，不把营销话术当卖点抄进报告。
