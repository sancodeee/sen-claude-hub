# ResumeForge 优化前行为基线（RED）

评测日期：2026-09-01。所有运行均为 `gpt-5.6-terra`、`medium`、全新隔离上下文；场景使用 [scenarios.md](scenarios.md) 的 S1 合成事实。无技能控制组不读取任何 ResumeForge 文件；现版组读取修改前的 `1.0.0` Skill 与全部 references。

## 无技能控制组

运行标签：`baseline_control`。

- 结果：实际生成可投递样式正文。
- 失败：把 Redis 从“了解”写入“熟悉”技术栈；生成未提供的“负责相关后端功能”“上线支持”“提升可维护性”等职责和结果；保留缺少完整口径的团队 `40%` 指标。
- 结论：默认简历写作行为不能稳定守住事实与个人贡献边界，ResumeForge 的事实契约有必要保留。

## RED 结论

原有真实性门禁有效，但交付契约只有散落的禁止项，没有互斥的正向输出结构；在截止时间与“不要提问”压力下，模型会用审阅稿作为折中方案。优化目标应是固定输出路由和正文边界，而不是增加更多事实禁令。
